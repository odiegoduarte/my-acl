<h2 align="center">📜 ACLs</h2>
<br>

Este repositório contém uma lista de domínios que em algum momento utilizei para realizar liberações ou bloqueios em ambientes de Firewall, Proxy e filtros de acesso.

Este projeto não emite opiniões ou recomendações. Em outras palavras, ele **não endossa, afirma ou implica** que um domínio deva ser bloqueado ou liberado.

O objetivo é apenas manter uma base de referência, mantida de forma comunitária, que pode ser utilizada para consultas e para geração de regras sob demanda, de acordo com a necessidade de cada ambiente. As listas são baseadas em uso e experiência prática e podem conter URLs que se tornem obsoletas ou deixem de ser válidas ao longo do tempo. Utilize por sua conta e risco.
