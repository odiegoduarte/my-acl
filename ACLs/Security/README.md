# ACLs - Proteção

## Bitdefender

Esta seção descreve as portas de comunicação utilizadas pelos componentes do GravityZone quando a solução de segurança é instalada nas instalações da sua empresa.

Você precisa manter essas portas abertas e excluir todos os endereços mencionados nesta tabela de qualquer solução de segurança de gateway ou inspeção de pacotes de rede para que o GravityZone funcione perfeitamente.
